# 🚗 Smart Parking UTEQ

Sistema de gestión y monitoreo para el control de estacionamientos, vehículos autorizados y directorio de propietarios de la **Universidad Técnica Estatal de Quevedo (UTEQ)**.

---

## 📌 Características Principales

* **Gestión de Vehículos (CRUD):** Registro, edición, filtrado y actualización de datos de vehículos autorizados (placa, propietario, cédula, marca, modelo, tipo y estado).
* **Monitoreo de Puestos:** Panel gráfico e interactivo para consultar la disponibilidad de parqueaderos (*Disponible* / *Ocupado*) clasificados por categoría (*Preferencial* / *General*).
* **Directorio de Propietarios:** Asignación de vehículos a la comunidad universitaria (estudiantes y personal administrativo) utilizando su correo institucional UTEQ.
* **Interfaz Adaptable & Temas:** Soporte completo para **Modo Claro** y **Modo Oscuro** (*Dark Mode*), además de diseño *Responsive* para dispositivos móviles.
* **Búsqueda Rápida:** Filtros en tiempo real por placa, cédula, nombre o modelo del vehículo.

---

* **Frontend:** React.js

* **Estilos:** CoreUI UI Components / CSS3
